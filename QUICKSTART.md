# Quickstart

The shortest path is in the [README](README.md).

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e ".[dev,server]"
opencobalt ui
```

That opens the local workspace at `http://localhost:5173`. Chat is the default
page.
