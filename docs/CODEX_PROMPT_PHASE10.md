### Deliverable 1: Tauri Desktop App wrapper

Replace the `opencobalt ui` localhost web approach with a standalone desktop app.

**Why Tauri over Electron:**
- ~8MB binary vs ~150MB Electron bundle
- Rust backend, no Node runtime bundled
- Uses system WebView (WKWebView on macOS) — familiar for the existing React frontend
- Simpler distribution (single binary, no installer)

**What to do:**
1. Install Tauri CLI and prerequisites: `cargo install tauri-cli` (if not present)
2. Initialize Tauri in the `ui/` directory: `cargo tauri init`
3. Configure `tauri.conf.json`:
   - `productName`: "OpenCobalt"
   - `devUrl`: "http://localhost:5173"
   - `frontendDist`: "../dist"
   - Window size: 1200×800, min 900×600
   - Title bar: hidden (use custom title bar in React)
4. Keep the FastAPI backend running on port 8000 — Tauri just wraps the WebView
5. Add `opencobalt desktop` command to `src/opencobalt/cli.py` that:
   - Starts FastAPI server (port 8000) in a background thread
   - Runs `cargo tauri dev` (dev) or the compiled binary (prod)
   - On exit, stops the FastAPI server
6. Build script: `ui/build-desktop.sh` that runs `cargo tauri build`

**Files to create/modify:**
- `ui/src-tauri/` (auto-generated by tauri init)
- `ui/src-tauri/tauri.conf.json` (configure as above)
- `src/opencobalt/cli.py` — add `desktop` command (follow existing `ui` command pattern)
- `ui/package.json` — add `"desktop": "tauri dev"` script

### Deliverable 2: Animated Routing Visualization

Add a "routing graph" view to the React dashboard that animates whenever a route decision is made.

**Design:** ComfyUI-style but cleaner. Dark background (var(--bg) = #080A0F). Nodes pulse to life as routing happens. Edges carry animated electricity (dashed animated stroke). Each node shows the tool name, its tier, and current status.

**React component:** `ui/src/RoutingGraph.jsx`

**Node layout:**
```
[Prompt Input] → [Router] → [Winner Tool]
                     ↘ [Runner-up 1]
                     ↘ [Runner-up 2]
```

**Node states:**
- `idle`: dim, 0.3 opacity
- `active`: full opacity, blue glow (var(--acc) = #7B9EFF)  
- `winner`: green glow (var(--ok) = #3DFFA0)
- `runner-up`: amber, 0.6 opacity (var(--wn) = #FFD166)

**Edge animation:** SVG `<path>` with `stroke-dasharray` and `stroke-dashoffset` CSS animation. When a route fires, a "pulse" travels from source to dest over 400ms.

**Integration:**
- Subscribe to route events: poll `/api/timeline` every 2s or use WebSocket if available
- When a new route event appears, trigger the animation sequence:
  1. Prompt node activates (100ms)
  2. Router node activates + edges to all tools light up (200ms)
  3. Winner tool node goes green; runners dim (400ms)
  4. Hold for 2s, then fade all back to idle
- Add "graph" nav item to the sidebar in `App.jsx`
- Data source: the `scores` dict from route decisions (already stored in ledger metadata)

**API change needed:** Expose scores per route decision in `/api/timeline` entries. The scores are already stored in `metadata._scores` — extract and include them.

**Files to create/modify:**
- `ui/src/RoutingGraph.jsx` — new component
- `ui/src/App.jsx` — add Graph nav item, import RoutingGraph
- `src/opencobalt/api_server.py` — expose `scores` in `/api/timeline` entries
