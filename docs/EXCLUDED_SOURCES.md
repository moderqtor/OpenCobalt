# Excluded Sources

This document records what was audited and excluded when extracting public-safe content for OpenCobalt.

## Source Material

A previous private workspace served as the reference codebase during initial design. That workspace contained session logs, generated indexes, environment-specific credentials, and private path configurations. None of that material is included here.

## Categories of Excluded Content

| Category | Reason |
|----------|--------|
| Secrets and credential files | Any file containing API keys, passwords, or tokens |
| Environment configuration | `.env` files with deployment-specific values |
| Session transcripts and logs | Raw session output, private prompts, personal data |
| Vector index artifacts | Local embedding indexes tied to private knowledge bases |
| Private path references | Paths to local vaults, personal directories, or named internal systems |
| Generated bytecode | `__pycache__/`, `.pyc` files |
| Archive and snapshot directories | Old experiments and private session snapshots |

## Files Used as Reference (Rewritten, Not Copied)

Logic and design patterns from the private workspace were rewritten from scratch for this repo. No raw content was copied.

| Source Pattern | Used For | Status |
|----------------|----------|--------|
| Event spine design | `opencobalt/core/events.py` | Adapted and rewritten |
| Router scoring logic | `opencobalt/core/router.py` | Rewritten, same deterministic approach |
| Schema patterns | `opencobalt/core/models.py` | New schemas written independently |
| Architecture doctrine | `docs/ARCHITECTURE.md` | Rewritten for OpenCobalt scope |

## Third-Party Repos

No third-party repositories are vendored into OpenCobalt. See `CREDITS.md` for attribution and `docs/INTEGRATIONS.md` for the integration pattern.

## Public Safety Checks

The `opencobalt public-check` command scans for: `.env` pattern files, secret patterns (API keys, tokens, passwords), oversized artifacts, and private path references. It must pass clean before any push.
